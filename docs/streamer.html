Set up ChatCraft.

Minecraft 1.21.1 · Fabric · Java 21

1. Install

  1. Install Fabric Loader.
  2. Add Fabric API, Mod Menu, and ChatCraft to the mods folder.
  3. Open Minecraft → Mods → ChatCraft → Open Web Panel.

2. Connect Twitch

  1. Create a Twitch application.
  2. Select Public and Chat Bot.
  3. Copy the exact redirect URL from the ChatCraft panel into Twitch.
  4. Paste the Client ID into ChatCraft and select Authorize.
  5. Save the token and connect.

The OAuth token is encrypted locally and never logged. The Client ID is public.

3. Configure

Moderator commandsThe broadcaster and Twitch moderators can send commands such as cmd time set day.
TestRun /chatcraft test W

Only enable moderator commands for people you trust. Minecraft still enforces the in-game account's command permissions.

Quick fixes

Twitch will not connect

Authorize again and verify the account and Client ID.

Follow events require authorization

Authorize Twitch again to grant the follower permission to the new token.

Commands do nothing

Check Controls, the prefix, and access lists. Then run /chatcraft test W.

World rules fail

Enable cheats or grant the Minecraft account operator access.

The localhost OAuth page fails

Keep Minecraft running and use the exact redirect URL shown in the panel.
