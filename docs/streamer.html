Set up ChatCraft

Minecraft 1.21.1 · Fabric · Java 21

1. Install

  1. Install Fabric Loader.
  2. Add Fabric API, Mod Menu and ChatCraft to the mods folder.
  3. Start Minecraft → Mods → ChatCraft → Open Web Panel.

2. Connect Twitch

  1. Create a Twitch application.
  2. Select Public and Chat Bot.
  3. Copy the exact redirect URL from the ChatCraft panel into Twitch.
  4. Paste the Client ID into ChatCraft and click Authorize.
  5. Save the token and connect.

The OAuth token is encrypted locally and never logged. The Client ID is public and does not need encryption.

Quick fixes

Twitch will not connect

Authorize again and verify the account, Client ID and chat:read scope.

Commands do nothing

Check Controls, prefix and access lists. Then run /chatcraft test W.

World rules fail

Enable cheats or grant the Minecraft account operator permission.

OAuth localhost page fails

Keep Minecraft running and use the exact dashboard redirect URL.
