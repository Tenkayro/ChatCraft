STREAMER SETUP

From install to live chat in four steps.

Connect Twitch, YouTube, or both. The local dashboard guides you through authorization and keeps credentials encrypted on your computer.

Minecraft 1.21.1 Fabric Java 21

01

INSTALL

Add ChatCraft to Minecraft

  1. Install Fabric Loader for Minecraft 1.21.1.
  2. Place Fabric API, Mod Menu, and ChatCraft in the instance's mods folder.
  3. Start Minecraft and open Mods → ChatCraft → Open Web Panel.

Keep Minecraft open while using the dashboard. The panel runs locally and stops when the game closes.

02

TWITCH

Authorize your Twitch channel

  1. 1

    Create a Twitch application and choose Public and Chat Bot.

  2. 2

    In ChatCraft's dashboard, expand Twitch setup and copy the redirect URL.

  3. 3

    Add that exact URL to the Twitch application, then paste its Client ID into ChatCraft.

  4. 4

    Select Authorize, approve access, save the returned token, and connect.

The OAuth token is encrypted locally and never written to logs.

03

YOUTUBE

Connect your YouTube live chat

  1. 1

    Create a project in Google Cloud Console and enable YouTube Data API v3.

  2. 2

    Create an OAuth client for a Web application.

  3. 3

    Expand YouTube setup in ChatCraft and add its exact redirect URL as an authorized redirect URI.

  4. 4

    Enter the Client ID and Client Secret, authorize the streaming channel, then select Connect.

Start your YouTube broadcast before connecting. ChatCraft detects its live chat automatically and ignores old chat history.

04

CONFIGURE

Choose how chat can play

Chat controlEnable or pause commands without disconnecting.

Command prefixOptional. Use ! if normal conversation triggers too many commands.

Viewer accessUse the whitelist or blacklist to control who can play.

ReconnectRecover interrupted Twitch and YouTube connections automatically.

Slot overlayShow green labels for inventory slots, recipes, and buttons.

Moderator commandsAllow trusted owners and moderators to use the ? command prefix.

Moderator commands can run anything the in-game account is allowed to run. Only enable them for people you trust.

QUICK FIXES

Common setup problems

Twitch does not connect

Authorize Twitch again and verify that the selected account and Client ID match.

YouTube cannot find a chat

Make sure the authorized channel owns or moderates the broadcast, the broadcast is live, and live chat is enabled.

Chat commands do nothing

Check Chat control, the optional prefix, and viewer access lists. Then test with /chatcraft test W.

The OAuth page reports a redirect error

Copy the redirect URL again from the dashboard. It must match exactly, including HTTPS and the port.

World rules fail

Enable cheats in singleplayer or grant the Minecraft account operator permission.
