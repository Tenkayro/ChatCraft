VIEWER GUIDE

Control Minecraft from Twitch or YouTube chat.

Send a command as a normal chat message. Commands are not case-sensitive: w, W, and forward do the same thing.

Try it nowWThe player moves forward.
Optional prefixIf the streamer uses a prefix, add it once at the start: !W+SPACE.
Nothing gets lostCommands enter a queue and run in chat order.
Aim mattersBREAK, PLACE, and USE affect what the player is looking at.

SYNTAX

Build a command

1

One action

W

Runs one action.

2

In sequence: space

W RIGHT BREAK

Move, then turn, then break.

3

At once: plus

W+SPACE

Move forward and jump together.

4

Duration: dot + seconds

W.1.5

Hold forward for 1.5 seconds.

Remember: a space means then. A + means at the same time.

INVENTORY & RECIPES

Use the green labels

Visible slots and recipes receive short green labels.

Using the inventory

  1. Send E.
  2. Find the green label on the slot you want, such as B2.
  3. Send that exact label in chat.
  4. Send ESC to close the inventory.
Send in chatAliasesResult
EINVENTORY INVOpen or close the player inventory
ESCCLOSEClose the current inventory or screen
A1Any visible green slot labelLeft-click that slot
RA1Add R before the labelRight-click that slot
SA1Add S before the labelShift-click that slot
U1Any visible green U labelPress that button or control

RECIPE BOOK IN 4 STEPS

  1. Send BOOK.
  2. Optionally select a green category with T1, T2, and so on.
  3. Select a visible recipe with R1 through R20.
  4. If variants appear, choose one with V1, V2, and so on.

Three click types

B2 = left-click

RB2 = right-click

SB2 = shift-click

Buttons everywhere: visible controls in containers and other screens use U1, U2, and so on. The pause menu is intentionally excluded.

TROUBLESHOOTING

If nothing happens

The command is waiting: an earlier movement or BREAK action is still running.

PLACE or BREAK fails: the player is not looking at a valid target.

The recipe does not fill: ingredients are missing or it does not fit the 2×2 crafting grid.

Every command is ignored: check whether the streamer requires a prefix such as !.
