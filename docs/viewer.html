VIEWER COMMANDS

Play Minecraft through Twitch chat

Send several commands in one message. Spaces run commands in order; + runs commands at the same time. Commands are not case-sensitive.

PrefixUse the streamer's prefix if enabled, for example !W.
QueueEvery valid command waits its turn; commands are never dropped by a cooldown.
TargetWorld actions affect whatever the player is currently looking at.
MovementCameraGameplayInventory

MOVEMENT

Move the player

Movement lasts for the duration configured by the streamer.

Combos: W A BREAK runs the three commands one after another. W+SPACE holds forward and jump together. Add seconds with a dot, for example W.1+SPRINT.1. Decimal durations such as W.0.5 are supported up to 30 seconds.

INVENTORY

Open screens and click slots

Green labels appear over usable slots while an inventory or container is open.

Type in chatAlso worksResult
EINVENTORY INVOpen or close the player inventory
RECIPEBOOKRECIPES BOOKOpen the inventory recipe book or close it again
RECIPE1 to RECIPE20Copy a visible green recipe labelSelect that recipe and fill the crafting grid when ingredients are available
RECIPENEXTNEXTRECIPEOpen the next recipe page
RECIPEBACKRECIPEPREV PREVRECIPEOpen the previous recipe page
ESCCLOSEClose the current inventory or container
A1Any visible labelLeft-click that exact slot
RA1R + labelRight-click that exact slot
SA1S + labelShift-click that exact slot

How labels are arranged

Letters are columns. Numbers are rows. Always copy the green label currently visible in Minecraft.

A1B1C1A2B2C2A3B3C3

Example

B2 left-clicks the center slot.

RB2 right-clicks it.

SB2 shift-clicks it.
