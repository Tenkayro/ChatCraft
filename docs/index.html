Install

  1. Install Fabric Loader for Minecraft 1.21.1.
  2. Put Fabric API, Mod Menu and the ChatCraft JAR into .minecraft/mods.
  3. Start Minecraft and open ChatCraft from Mod Menu.
  4. Click Open Web Panel.

Connect Twitch

  1. Open the Twitch Developer Console.
  2. Create a Public application in the Chat Bot category.
  3. Copy the exact redirect URL shown by ChatCraft into the Twitch application.
  4. Paste the Client ID into ChatCraft and click Authorize.
  5. Save the validated token, then click Connect.

The token is encrypted locally and is never written to logs. Keep the generated key file together with your Minecraft installation and never share either file.

Inventory and containers

ChatCraft labels the real slots of any handled vanilla screen. The label is rendered above the item and a virtual cursor shows chat interactions.

ExampleAction
A1Left-click slot A1
RA1Right-click slot A1
SA1Shift-click slot A1

It uses Minecraft's ScreenHandler and Slot APIs, never desktop mouse coordinates.

Dashboard and OBS

The local HTTPS panel manages Twitch, controls, cooldowns, access lists and the activity log. World-rule buttons request keepInventory and doImmediateRespawn for the open world; cheats or operator rights are required.

Copy the OBS URL from the dashboard into an OBS Browser Source. The transparent overlay shows Twitch colors, badges and 7TV emotes.

Troubleshooting

Twitch will not connect
Validate the token again, verify chat:read, and check that the configured username matches the token account.
OAuth page says localhost is unavailable
That is expected only if Minecraft is not running. Open the dashboard first and use its exact redirect URL.
Commands appear but do nothing
Enable Controls, check prefix/cooldown and whitelist/blacklist, then use /chatcraft test W.
World rules fail
Enable cheats in singleplayer or grant the connected account operator permission on the server.
