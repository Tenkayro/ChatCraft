# ChatCraft

ChatCraft is a client-side Fabric mod for Minecraft 1.21.1 that lets Twitch chat directly control the game.

Viewers can control movement, jumping, sneaking, sprinting, camera direction, hotbar selection, inventory access, item dropping, attacking, using items, respawning, and real Minecraft inventory/container slots.

ChatCraft uses Minecraft's own key bindings and slot interaction APIs. It does not use desktop mouse automation.

It includes a clean local HTTPS dashboard for configuration, Twitch OAuth setup, connection status, chat messages, command decisions, and executed actions. Mod Menu is only used to select the dashboard port and open the panel.

Full documentation is available on the [ChatCraft Guide](https://tenkayro.github.io/ChatCraft/).
